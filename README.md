# PRG282 - Animal Management System Group 10

## Project Overview
The **Animal Management System** is a C# Windows Forms desktop application designed to manage, track, and update animal records in a structured data store. This project demonstrates core Object-Orientated Programming (OOP) principles, event handling, data persistence, and Git collaboration.

---

## Features
* **View Animals:** Display all recorded animals in a 'DataGridView' UI component.
* * **Add Animal:** Insert new animal records with species and attribute parameters.
* **Update Animal:** Search and edit existing animal records.
* **Delete Animal:** Remove specified animal records from the collection.

---

* **Framework:** .NET Framework / WinForms
* **IDE:** Microsoft Visual Studio
